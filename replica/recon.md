# Recon map: Zapret 2 (Windows desktop, v21.1.1.7)

Scope: ядро обхода DPI и всё, что вокруг него: пресеты и стратегии, автоподбор, списки сайтов, DNS/hosts, локальный прокси для Telegram, диагностика. Платные темы, донаты и «твики Windows» в объём не входят.
For: open-source клиент с адаптацией под регион (Россия, Турция, Иран, Китай) для Android и Windows. Обход DPI плюс прокси по ключу пользователя. Стек: Flutter, sing-box, ByeDPI.
Date: 2026-10-26

Метод: только публичные источники и установленная копия пользователя. Смотрели структуру папок, файлы данных (пресеты, каталоги стратегий, списки, настройки) и главный экран. Код (`_internal`, `.lua`, `.py`) не читали и не декомпилировали. Остальные экраны снять не удалось: приложение запущено от администратора, и Windows не пропускает в него программный ввод. Их состав восстановлен по боковому меню, настройкам и статьям. Состояния этих экранов помечены как «не видели».

## Inferred data model

```
Preset      file_name, name, builtin_version, icon_color, description, engine (winws1|winws2),
            is_builtin, global_filter (--wf-tcp/--wf-udp), profiles[]
            evidence: presets/*/*.txt (заголовок # Preset/# IconColor/# Description)
            confidence: high

Profile     name/comment, filter_tcp ports, filter_udp ports, filter_l7 (tls|quic|stun|…),
            hostlist ref | ipset ref, exclude lists, strategy ref | inline desync args
            evidence: блоки между --new в пресетах, system/templates/all_profiles.txt
            confidence: high

Strategy    id, name, author, label (experimental…), blobs[], description, category (tcp|udp|http80|voice),
            args[] (--lua-desync=… или --dpi-desync=…), status for user (works|broken|unknown)
            evidence: system/strategy_catalogs/winws2/*.txt; «цветные отметки» из статьи
            confidence: high (status — medium)

DomainList  name, kind (hostlist|ipset), entries[], origin (base|user)
            evidence: lists/, lists/base/
            confidence: high

Blob        name, file (.bin), protocol (tls|quic|http|stun|…)
            evidence: bin/
            confidence: high

Settings    program{dpi_autostart, gui_autostart, strategy_launch_method, selected_preset per engine,
            auto_update, discord_auto_restart, max_blocked, russian_state_media_blocked, defender_disabled},
            window{…, tray_close_mode}, appearance{theme, language, mica, accent, backgrounds, effects},
            warnings{…}, telegram_proxy{enabled, host, port, mode, upstream_*}
            evidence: settings/settings.json
            confidence: high

StrategyStat host, strategy, successes, failures, locked (strategy-lock-manager)
            evidence: lua/strategy-stats.lua, strategy-lock-manager.lua (только имена файлов)
            confidence: guess

HostsEntry  service, domain, ip
            evidence: system/hosts_catalog.sqlite3 (схему не читали)
            confidence: guess
```

Relationships: Preset 1-n Profile; Profile n-1 Strategy; Profile n-1 DomainList; Strategy n-n Blob; StrategyStat n-1 Strategy.

Как это ложится на наш клиент: `Preset` становится **региональным профилем** (страна плюс провайдер), `Profile` — **правилом маршрутизации** (группа доменов → direct | desync(стратегия) | proxy(ключ)), `Strategy` — **записью в подписанной базе стратегий**. Добавляются `ProxyKey` (vless/hy2/trojan/ss URI, подписка) и `Region` (код страны, ASN провайдера, источник определения).

## Out of scope (cannot or should not be cloned)

- **«Отключить Windows Defender».** Снижает безопасность пользователя, в open-source клиенте этого быть не должно.
- **«Блокировать установку MAX» и блокировка госСМИ.** Политические твики под одну страну, к обходу блокировок не относятся.
- **Платный уровень, донат-темы, «РКН-тян», гирлянда.** Оформление и монетизация конкретного автора. У нас open source без платных функций.
- **Их пресеты, каталоги стратегий, .bin-блобы и Lua-скрипты как есть.** Сначала проверить лицензию. Движки bol-van (zapret, zapret2) открыты, авторство GUI-каталогов — нет. Свою базу стратегий собираем заново, из документации движков и вкладов сообщества.
- **Переименованный драйвер WinDivert (`Monkey64.sys`).** Маскировка драйвера под другое имя — не то, что стоит повторять. Используем Wintun и sing-box, а WinDivert только как официальный отдельный режим.
- **Распространение через Telegram-канал автора.** Это его аудитория. У нас GitHub Releases и F-Droid.

## Чего у оригинала нет — наша ниша

- Только Windows и только Россия: списки, фильтры по AS (МТС), блобы под российские сайты. Нет Android, Турции, Ирана, Китая.
- Нет прокси по ключу: Telegram-прокси работает только для Telegram, по IP заблокированное не открыть.
- Выбор перегружен: 256 пресетов и 690 стратегий, обычный пользователь перебирает вслепую (F02).
- Автоподбор (circular) — отдельный режим для продвинутых, а не поведение по умолчанию. Логи разрастаются до гигабайта.
- Нужны права администратора, сложности с антивирусами.

## Size

Screens 13 (+трей и поиск), flows 8, entities 7 (+2 наших: ProxyKey, Region).
Hard parts:
1. **Обход DPI на Android без root.** Через VpnService доступны только приёмы на уровне сокетов (split, disorder, OOB, fake через TTL в ByeDPI). Пакетного уровня, как в WinDivert, нет, поэтому часть стратегий zapret на Android невоспроизводима.
2. **Автоподбор стратегии.** Нужен детектор блокировки (таймаут, RST, заглушка провайдера, нет ответа по UDP), перебор без порчи работающего трафика и привязка результата к провайдеру (ASN).
3. **Связка движков.** Через один TUN маршрутизировать трафик напрямую, через ByeDPI или через прокси по ключу, одинаково на Android и Windows. Плюс подписанная обновляемая база стратегий.

Size: **L** (квартал) для Android и Windows с автоподбором. MVP (импорт ключа, региональные профили, ручной выбор и простой автотест) — M.

## Что берём и чего у Hiddify нет

- Берём: модель «профиль = ссылка или подписка» с трафиком и сроком; импорт из буфера в 1 клик; большую кнопку; выбор региона в маршрутизации; режимы «прокси» и «VPN (TUN)»; фрагментацию TLS как простой тумблер.
- У Hiddify нет локального обхода DPI без сервера: фрагментация есть, но только для трафика к прокси. Без ключа он бесполезен.
- Регион у Hiddify меняет только «что пускать напрямую», а не способ обхода.
- Аналитика включена по умолчанию. У нас наоборот: выключена.

## Объединённый продукт (рабочее название «Обход»)

Одна кнопка, три режима, режим выбирается регионом и наличием ключа:

| режим | что делает | откуда идея |
| --- | --- | --- |
| **Обход DPI** | сайты из списков → локальный ByeDPI (split, disorder, OOB, fake), остальное напрямую. Сервер не нужен | Zapret |
| **VPN по ключу** | всё → сервер по ключу, кроме локальных адресов и сайтов своей страны | Hiddify |
| **Гибрид** (по умолчанию, если есть ключ) | DPI-списки → ByeDPI, заблокированное по IP → ключ, остальное напрямую | новое |

Региональный профиль задаёт режим по умолчанию, кандидатов стратегий ByeDPI для автоподбора, DoH-сервер и списки. Для Китая без ключа приложение честно говорит, что нужен ключ.

Size (объединённый): MVP для Windows — M, полная версия для Android и Windows — L.
