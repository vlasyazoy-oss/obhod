# Обход (черновик 0.1)

Open-source клиент, который совмещает два подхода:

- **обход DPI без сервера**, как Zapret: локальный [ByeDPI](https://github.com/hufrea/byedpi);
- **VPN по своему ключу**, как Hiddify: [sing-box](https://github.com/SagerNet/sing-box), ключи vless, vmess, trojan, ss, hysteria2, tuic и подписки.

Режим и стратегия зависят от региона: Россия, Турция, Иран, Китай или другая страна.

Windows- и macOS-версия: Python и tkinter (корень папки; про Mac — [MACOS.md](MACOS.md)). Android-версия: Kotlin, папка `android/` (собирается, на устройстве ещё не проверялась).

## Запуск

```
py scripts/fetch_bins.py                        # скачать sing-box 1.14.4 и ByeDPI 0.17.3 с GitHub в bin/
py -m pip install --user -r requirements.txt    # трей и QR: Pillow, pystray, zxing-cpp
py app.py                                       # или py app.py --tray — сразу свёрнутым в трей
```

Нужен Python 3.8+. Без библиотек из requirements.txt приложение тоже работает, но без трея и QR.

## Готовый exe

```
py -m pip install --user pyinstaller
py -m PyInstaller --onefile --windowed --name Obhod --icon obhod.ico --add-data "core/regions.json;core" --hidden-import pystray._win32 --hidden-import truststore --exclude-module numpy app.py
```

- В exe нет движков (sing-box весит 82 МБ): при первом запуске он предлагает скачать их с GitHub в `%LOCALAPPDATA%\Obhodin`. Настройки и журнал лежат в `%LOCALAPPDATA%\Obhod\data`.
- `Obhod.exe --selftest` без окон скачивает движки, подключается в режиме «Обход DPI» на отдельных портах (системный прокси не трогает), открывает тестовые сайты и пишет отчёт в `%LOCALAPPDATA%\Obhod\data\selftest.txt`.
- Exe не подписан: SmartScreen предупредит при первом запуске.

## Ключи

- Подписки скачиваются с проверкой сертификата через хранилище Windows, как в браузере (`truststore`): корпоративные фильтры и антивирусы, которым доверяет система, не мешают. Если сертификат всё равно не подтверждён (самоподписанный у сервера), «Обход» показывает его отпечаток SHA-256 и спрашивает, доверять ли. Согласие запоминает отпечаток для этого сервера: другой сертификат снова вызовет вопрос.
- **Вставить**: текст из буфера (ключ, несколько ключей, base64-подписка, JSON sing-box, ссылка на подписку). Если в буфере картинка, на ней ищется QR.
- **QR с экрана**: окно прячется, снимаются все мониторы, найденные QR-коды импортируются. Можно открыть QR из Telegram или из панели провайдера и нажать кнопку.
- **QR из файла**: картинка с QR-кодом.

## Трей и автозапуск

- Значок в трее — та же эмблема: глаза закрыты — отключено, открыты — подключено. Двойной клик открывает окно, правый клик — меню «Показать окно», «Подключить/Отключить», «Выход».
- Крестик прячет окно в трей. Выйти можно из меню значка.
- «Запускать вместе с Windows» пишет в `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` команду `pythonw.exe app.py --tray`, прав администратора не нужно. Если папку с программой перенесли, путь обновится при следующем запуске.
- «Подключаться сразу после запуска» — подключение без нажатия кнопки.
- Второй экземпляр не запускается и подсказывает, что программа уже в трее.

## Android (черновик)

```
TUN (VpnService) → hev-socks5-tunnel → SOCKS 127.0.0.1:2080 sing-box → напрямую / ByeDPI 127.0.0.1:1080 / сервер по ключу
```

- Root не нужен: используется системный VPN Android. Само приложение исключено из VPN, поэтому sing-box и ByeDPI выходят в сеть напрямую, без петли.
- sing-box и ByeDPI — официальные Linux/Android-сборки, упакованные в APK как `libsingbox.so` и `libbyedpi.so` (запускать бинарники Android разрешает только из папки нативных библиотек). Туннель — `hev-socks5-tunnel.aar`.
- Профили регионов общие с Windows-версией: `core/regions.json` копируется в APK при сборке.
- Регион по стране SIM-карты, затем сети, часовому поясу и языку.
- Постоянное уведомление с кнопкой «Отключить» — аналог трея.

```
py scripts/setup_android.py        # JDK 21, Android SDK, Gradle и движки; принимает лицензию Android SDK
cd android && gradle assembleRelease # APK по архитектурам: app/build/outputs/apk/release/app-arm64-v8a-release.apk и др.
gradle testDebugUnitTest           # тесты ключей и конфига; сохраняют конфиги для проверки
py scripts/check_android_configs.py # проверка этих конфигов настоящим sing-box
```

Нужен Android 10+ (этого требует hev-socks5-tunnel). Релизная сборка — отдельный APK на архитектуру (телефонам нужен arm64, ~25 МБ). Официальные релизы подписаны ключом из `keys/keystore.properties` в корне репозитория — его нет в git. Без него сборка подписывается отладочным ключом, и такой APK не встанет поверх официального.

Нет пока: QR-сканера камерой, автоподбора стратегии, автозапуска при включении телефона, выбора приложений для VPN.

## Режимы

| режим | маршрут |
| --- | --- |
| Обход DPI | сайты из списка региона → ByeDPI, остальное напрямую; QUIC к ним режется, чтобы браузер ушёл на TCP |
| VPN по ключу | всё → сервер, кроме локальной сети и сайтов своей страны |
| Гибрид | `proxy_domains` → сервер, `dpi_domains` → ByeDPI, остальное напрямую |

По умолчанию трафик идёт через системный прокси `127.0.0.1:2080` (без прав администратора). Режим TUN перехватывает весь трафик системы и требует запуска от администратора.

Системный прокси ставит и снимает само приложение (`core/sysproxy.py`). Прежние настройки сохраняются в `data/proxy_backup.json`, и при следующем запуске после сбоя они возвращаются.

## Устройство

```
app.py              интерфейс
core/regions.json   профили регионов: списки доменов, DoH, стратегии ByeDPI, тестовые сайты
core/keys.py        разбор ключей и подписок → outbound sing-box
core/config.py      сборка конфига sing-box под регион и режим
core/engine.py      запуск ciadpi и sing-box, журнал с лимитом 1 МБ
core/autotest.py    автоподбор: перебор стратегий ByeDPI на тестовых сайтах через curl
core/region.py      регион по часовому поясу и языку; по IP — только по кнопке
core/sysproxy.py    системный прокси Windows с резервной копией
core/emblem.py      эмблема: векторная для окна, растровая для значков
core/tray.py        значок в трее (pystray)
core/autostart.py   автозапуск через HKCU\...\Run
core/qr.py          QR: с экрана, из файла, из буфера (zxing-cpp)
core/state.py       настройки в data/state.json
```

## Ограничения черновика

- Стратегии в `regions.json` — стартовый набор. Их надо проверять в каждой стране, и у разных провайдеров работают разные.
- Рабочая стратегия запоминается для региона, а не для провайдера.
- Если запущен Zapret, он тоже обрабатывает трафик, и результаты автоподбора искажаются. Перед проверкой его стоит остановить.
- Трафик и срок подписки не показываются, проверки задержки серверов нет.
- `data/state.json` хранит ключи открытым текстом.
