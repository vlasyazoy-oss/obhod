# «Обход» на macOS

Mac-версия — тот же код, что Windows-версия, с отличиями:

| | Windows | macOS |
| --- | --- | --- |
| обход DPI | ByeDPI | встроенная в sing-box фрагментация TLS-записей (у ByeDPI нет сборки под macOS) |
| системный прокси | реестр | `networksetup`: HTTP- и HTTPS-прокси на всех включённых сетевых службах |
| автозапуск | реестр Run | LaunchAgent `~/Library/LaunchAgents/org.obhod.app.plist` |
| трей | есть | пока нет — окно сворачивается в Dock, выход — Cmd+Q |
| TUN | есть (от администратора) | пока нет |
| VPN по ключу, гибрид, QR | есть | есть |

> **Статус: собрано и проверено только на Windows.** Код Mac-версии и маршрутизация через sing-box проверены
> на Windows и на живой сети, но на настоящем Mac программа ещё не запускалась. Ниже — как это сделать.

## 1. Подготовка

- macOS 12 или новее, Apple Silicon или Intel.
- **Python с python.org** (3.11 или новее): в нём есть Tk, без которого не будет окна.
  Python от Homebrew тоже подойдёт, но нужно доставить Tk: `brew install python-tk`.

```bash
git clone https://github.com/vlasyazoy-oss/obhod.git
cd obhod/obhod
git switch feature/macos        # пока Mac-версия не влита в main
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
```

## 2. Самопроверка без окон (1 минута)

```bash
python3 app.py --selftest; cat data/selftest.txt
```

Скачает sing-box под ваш процессор в `bin/`, подключится в режиме «Обход DPI» на отдельных портах
(системный прокси не трогает), откроет тестовые сайты региона и запишет отчёт. Должно быть «ИТОГ: всё работает».

## 3. Тесты

```bash
python3 -m unittest discover -s tests
```

Тесты Windows-части (ByeDPI, реестр) на Mac пропускаются сами. Живые тесты Mac-маршрутизации запустятся,
если sing-box уже скачан (шаг 2).

## 4. Программа

```bash
python3 app.py
```

Проверьте по порядку:

1. **Подключение.** Нажмите на эмблему — глаза открываются. При первом включении macOS может спросить пароль
   администратора: программа меняет системный прокси через `networksetup`.
2. **Сайты в Safari/Chrome.** Discord и Roblox (в Турции) должны открываться.
3. **Прокси выставлен.** «Системные настройки → Сеть → Wi-Fi → Подробнее → Прокси»: HTTP и HTTPS — `127.0.0.1:2080`.
4. **Отключение.** Нажмите на эмблему ещё раз — в тех же настройках прокси вернулся как был, интернет работает.
5. **Cmd+Q при подключении.** Программа закрывается, прокси возвращается как был. Это важно: иначе после выхода
   пропадёт интернет. Если всё-таки пропал — выключите прокси в тех же настройках вручную и напишите нам.
6. **Автозапуск.** Галочка «Запускать при входе в macOS» → появился файл `~/Library/LaunchAgents/org.obhod.app.plist`.
7. **QR с экрана.** macOS попросит разрешение «Запись экрана» для Терминала/Python — без него снимок будет пустым.

Журнал программы — `data/obhod.log`.

## 5. Сборка Obhod.app

```bash
bash scripts/build_macos.sh
```

Получится `dist-mac/Obhod.app` и архив `dist-mac/Obhod-macos-arm64.zip` (или `x86_64`). Собранная программа хранит
движки и настройки в `~/Library/Application Support/Obhod`. Самопроверка собранной программы:

```bash
dist-mac/Obhod.app/Contents/MacOS/Obhod --selftest
cat ~/Library/Application\ Support/Obhod/data/selftest.txt
```

Программа не подписана сертификатом Apple. На своём Mac она откроется сразу; если передать архив другому человеку,
macOS скажет, что разработчик не проверен: правый клик по `Obhod.app` → «Открыть» → «Открыть».

## Что прислать, если что-то не так

- `data/selftest.txt` (или из `~/Library/Application Support/Obhod/data/` для собранной программы);
- вывод тестов;
- `data/obhod.log`;
- скриншот окна, если проблема в интерфейсе.
